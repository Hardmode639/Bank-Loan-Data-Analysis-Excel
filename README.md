# Bank Loan Data Analysis — Excel

An interactive Excel dashboard analyzing loan application, funding, and repayment data to evaluate loan portfolio risk and performance.

## Key Features

* **Data Modeling:** 38K+ records structured as an Excel Table with a calculated month-extraction column
* **KPI Tracking:** Total Applications, Total Funded Amount, Total Received Amount
* **Good vs. Bad Loan Analysis:** Segmented loan applications and funded amounts by risk status
* **Time Intelligence:** MTD and MOM Growth % calculations for funded amount, received amount, interest rate, and DTI
* **17 PivotTables + 28 PivotCharts:** Breakdowns by loan term, purpose, employment length, state, and home ownership
* **Interactive Dashboard:** Slicers across Summary, Overview, and Pivot sheets for dynamic filtering

## Tools & Skills

**Microsoft Excel · PivotTables · PivotCharts · Excel Formulas · Data Cleaning · Dashboard Design · Financial Data Analysis**
