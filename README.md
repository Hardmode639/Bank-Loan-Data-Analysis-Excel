# # An interactive Excel dashboard analyzing loan application, funding, and repayment data to evaluate loan portfolio risk and performance.<br><br>## Key Features<br>- **Data Modeling:** 38K+ records structured as an Excel Table with a calculated month-extraction column<br>- **KPI Tracking:** Total Applications, Total Funded Amount, Total Received Amount<br>- **Good vs. Bad Loan Analysis:** Segmented loan applications and funded amounts by risk status<br>- **Time Intelligence:** MTD and MOM Growth % calculations for funded amount, received amount, interest rate, and DTI<br>- **17 PivotTables + 28 PivotCharts:** Breakdowns by loan term, purpose, employment length, state, and home ownership<br>- **Interactive Dashboard:** Slicers across Summary, Overview, and Pivot sheets for dynamic filtering<br><br>## Tools & Skills<br>Microsoft Excel, PivotTables, PivotCharts, Excel Formulas (TEXT, growth-rate calculations), Data Cleaning, Dashboard Design, Financial Data Analysis
